# Dotfiles

Personal configuration files for a Wayland desktop on Arch Linux.

## Branches

| Branch | Description |
|--------|-------------|
| `main` | Primary dotfiles |
| `mina` | [Mina](https://github.com/blaszczyknorbert/mina) branch, an Arch Linux pseudo-distribution, tracked as a submodule in the installer and may diverge from `main` |

## What's included

- **river** - window manager init with keybindings and autostart
- **waybar** - status bar config and stylesheet
- **foot** - terminal emulator settings
- **mako** - notification daemon config
- **swaylock** - lock screen config
- **kanshi** - display configuration
- **nvim** - minimal Neovim init
- **zshrc / zprofile** - shell environment and autostart
- **systemd user services** - update checks, battery monitor, first-run setup, clipboard daemon, idle lock
